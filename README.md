# Farhan-Ali-Yusuf-C6240192

Sharaxaadda Assignment 3: Exception Handling

Assignment-kan wuxuu ku saabsan yahay samaynta barnaamij Java ah oo ardayda jaamacadda loogu diiwaangeliyo imtixaannada.

Barnaamijku wuxuu qaadanayaa xogta ardayga sida lambarka aqoonsiga, magaca, da'da, dhibcaha imtixaanka iyo tirada maaddooyinka uu iska diiwaangelinayo.

Wuxuu hubinayaa in xogta ardaygu sax tahay. Ardaygu waa inuu jiraa ugu yaraan 18 sano, dhibcaha imtixaankuna waa inay u dhexeeyaan 0 ilaa 100. Sidoo kale, ardaygu wuxuu iska diiwaangelin karaa ugu yaraan hal maaddo iyo ugu badnaan shan maaddo.
